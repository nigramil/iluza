# Training Planner

Автор: Илюза Гильмуллина

Описание:  
Это графическое приложение для планирования тренировок. Пользователи могут добавлять тренировки с указанием даты, типа и длительности. Есть возможность фильтрации по дате и типу, а также сохранения и загрузки данных в формате JSON.

Примеры использования:  
- Ввод данных и добавление новой тренировки.  
- Фильтрация по типу тренировки или дате.  
- Сохранение данных через меню «Файл» → «Сохранить».  
- Загрузка данных через меню «Файл» → «Загрузить».
